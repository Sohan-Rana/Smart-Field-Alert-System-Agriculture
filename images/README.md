# Images and demo media

Put your own photos and video here. The website (`index.html`) shows a **Demo** section automatically when these files exist:

| File name | What it is |
|-----------|-----------|
| `circuit-photo.jpg` | Photo of your real breadboard circuit |
| `demo.mp4` | Short video (20-30 s): move your hand in front of the PIR and show the red LED and buzzer turning on |

If a file is missing, that part is simply not shown. Keep the video under about 20 MB so the page loads quickly.
