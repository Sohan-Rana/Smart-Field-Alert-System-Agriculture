Introduction to Robotics

What is Robotics?

Robotics is a technology that uses sensors, controllers, and actuators to perform tasks automatically.

Sensor

Collects environmental data — for example, the PIR sensor detects motion. It acts as the "eyes" of the system.

Controller

Arduino receives data from sensors and makes decisions. It acts as the "brain" of the system.

Actuator

Executes decisions — such as lighting up an LED or sounding a buzzer. It acts as the "hands" of the system.

In this project, a smart system has been developed using Arduino that monitors agricultural fields and gives alerts when any movement or abnormal condition is detected.

Problem Statement

Why Field Security Matters

Crop fields are often unguarded at night, and damage is usually discovered only after it has happened.

Animals and Theft

At night, wild animals or intruders can enter the field and damage or take crops.

Guarding Is Hard

Staying awake all night in an open field is tiring, costs money and can be unsafe.

Late Discovery

The farmer usually sees the damage in the morning, when it is too late to act.

When Motion is Detected

  • ● Red LED turns ON
  • ● Buzzer sounds
  • ● Green LED turns OFF

Normal Condition

  • ● Green LED stays ON
  • ● Buzzer remains silent

PIR warm-up: After power-on the PIR sensor needs about 30 seconds to calibrate. During this time the Arduino blinks the green LED and ignores the sensor, so there are no false alarms at start-up.

Wiring Notes

  • ● LEDs: Arduino pin → 220Ω resistor → LED long leg (+). Short leg (−) goes to GND.
  • ● PIR (HC-SR501): VCC → 5V, OUT → D2, GND → GND. Check the pin names printed on the board.
  • ● Buzzer: Use an active buzzer. Longer leg (+) → D8, other leg → GND. A passive buzzer needs tone() instead.
  • ● Breadboard tip: Connect Arduino 5V and GND to the breadboard power rails, then branch from the rails.

Arduino Code

Source Code

Copy and upload this code to your Arduino board via Arduino IDE.

smart_field_alert.ino
// Smart Field Alert System // PIR Sensor (HC-SR501) + Red/Green LED + Active Buzzer // Wiring: PIR OUT -> D2 | Green LED -> D6 | Red LED -> D7 | Buzzer -> D8 // Each LED needs a 220 ohm resistor in series. #define PIR 2 #define RED 7 #define GREEN 6 #define BUZZER 8 #define WARMUP_SECONDS 30 bool lastMotion = false; void setup() { pinMode(PIR, INPUT); pinMode(RED, OUTPUT); pinMode(GREEN, OUTPUT); pinMode(BUZZER, OUTPUT); Serial.begin(9600); // PIR needs time to calibrate after power-up. // The green LED blinks while the sensor warms up. Serial.println("PIR warming up..."); for (int i = 0; i < WARMUP_SECONDS; i++) { digitalWrite(GREEN, HIGH); delay(500); digitalWrite(GREEN, LOW); delay(500); } Serial.println("System ready. Field is secure."); } void loop() { bool motion = (digitalRead(PIR) == HIGH); if (motion) { // Motion detected: alert! digitalWrite(RED, HIGH); digitalWrite(GREEN, LOW); digitalWrite(BUZZER, HIGH); if (!lastMotion) { Serial.println("Alert! Motion Detected!"); } } else { // Normal condition digitalWrite(RED, LOW); digitalWrite(GREEN, HIGH); digitalWrite(BUZZER, LOW); if (lastMotion) { Serial.println("Field clear."); } } lastMotion = motion; delay(100); }

More Versions

Two upgraded sketches built on the basic code above.

PIR + Ultrasonic

Alerts only when motion is detected and the object is closer than a set distance. The buzzer stops after 10 seconds.

GSM SMS Alert

Sends an SMS to the farmer's phone through a SIM800L module, at most once a minute.

These two sketches have not been tested on hardware yet. Compile and test them on your own board.

Limitations

Limitations

Knowing the limits of the project makes the evaluation honest.

  • Limited range and angle

    One HC-SR501 covers only a small area, so a large field needs several units.

  • Cannot identify what moved

    A PIR sensor reacts to any moving heat source: animal, person or even a small pet.

  • False alarms

    Strong sunlight, hot wind or sudden temperature changes can trigger the sensor. The ultrasonic version reduces this.

  • Needs power

    The basic version needs a 5V supply. Remote fields need a battery or solar panel.

  • Local alert only

    The farmer must be within hearing or sight distance. Use the GSM version for SMS alerts.

Future Improvement

Scope for Future Development

This basic system can be further upgraded with advanced features.

GSM Module

Adding a GSM module enables SMS alerts directly to the farmer's mobile phone. Remote security monitoring becomes possible from any location.

Camera Detection

A camera module can capture images of the intruder. This visual evidence can be stored and used later for identification or legal purposes.

Solar Power

Solar panels can power the system, making it operational in remote areas without access to conventional electricity sources.

Mobile App Integration

A mobile app enables real-time monitoring and control via WiFi or Bluetooth. Farmers can check status and receive push notifications on their phones.
